隐私政策 / Privacy Policy

生效日期 / Effective date：2026-11-10　·　最后更新 / Last updated：2026-11-10

本页面说明我们（下称「我们」）如何通过亚马逊广告接口（Amazon Ads API）获取与处理自有店铺的广告数据。本页面为公开隐私声明，对应我们在亚马逊开发者中心（developer.amazon.com）登录授权（Login with Amazon）安全配置文件中填写的 Consent Privacy Notice URL。

This page explains how we (referred to as "we") obtain and process advertising data of our own store through the Amazon Ads API. This is a public privacy notice corresponding to the Consent Privacy Notice URL declared in our Login with Amazon security profile on developer.amazon.com.

1. 我们是谁 / Who we are

我们是亚马逊阿联酋站（Amazon.ae）与沙特站（Amazon.sa）的日用百货卖家，经营垃圾袋、铅笔、水杯、食品储物罐等家居、文具与餐厨类商品。我们使用一套仅供内部使用的本地运营分析工具（下称「本工具」），通过亚马逊广告接口读取自有店铺的广告表现数据，用于经营分析。

We are a general merchandise seller on Amazon.ae (UAE) and Amazon.sa (Saudi Arabia), selling household, stationery and kitchenware items such as trash bags, pencils, cups and food storage containers. We operate an internally used, locally hosted analytics tool that reads our own advertising performance data through the Amazon Ads API for business analysis.

2. 我们获取的数据 / Data we access

本工具仅通过亚马逊广告接口读取我们自有卖家账户的以下广告数据，不获取任何其他卖家或买家的任何数据：

  • 广告活动、广告组、关键词与商品投放信息
  • 出价、预算与广告创意（素材）元数据
  • 广告表现指标：曝光、点击、转化、花费、销售额（ROAS / ACOS 等）
  • 由接口异步生成的广告报表文件

我们明确不获取、不下载、不存储任何买家个人身份信息（PII），包括但不限于买家姓名、地址、邮箱、电话、聊天或评价正文。

The tool only reads the following advertising data of our own seller account through the Amazon Ads API. It does not access any data of other sellers or buyers:

Advertising campaigns, ad groups, keywords and product targeting; bids, budgets and creative (asset) metadata; performance metrics such as impressions, clicks, conversions, spend and sales (ROAS / ACOS); and report files generated asynchronously by the API.

We do not obtain, download or store any buyer personally identifiable information (PII), including but not limited to buyer names, addresses, emails, phone numbers, message or review text.

3. 数据用途 / How data is used

所获取的广告数据仅用于以下内部目的，不用于任何对外服务、不对外出售、不用于营销：

  • 广告效果复盘（曝光、点击、转化、花费、ACOS / ROAS 分析）
  • 多品类利润核算与广告投入产出评估
  • 关键词与投放结构优化建议（仅内部决策参考）

Advertising data is used solely for the following internal purposes, never for any external service, never sold, and never used for marketing: advertising performance review (impressions, clicks, conversions, spend, ACOS / ROAS); multi-category profit and advertising ROI assessment; keyword and structure optimization suggestions (internal decision support only).

4. 数据存储与处理位置 / Storage and processing location

所有广告数据均在本公司自有的本地计算机上处理与保存，不上传任何公有云、第三方服务或外部模型，不通过接口自动创建、修改或删除任何广告活动（本工具为只读分析用途）。

All advertising data is processed and stored on company-owned local computers. It is never uploaded to any public cloud, third-party service or external model. The tool does not automatically create, modify or delete any campaign through the API; it is read-only for analysis.

5. 凭证安全 / Credential security

亚马逊广告接口的访问凭证（客户端标识、客户端密钥、刷新令牌、账户配置文件标识）仅保存在本机加密配置文件中，不写入代码仓库、不公开、不上传云端，仅由一名经授权的运营负责人在本机访问。

Amazon Ads API credentials (client identifier, client secret, refresh token, profile ID) are kept only in an encrypted local configuration file on company-owned computers. They are never written into code repositories, never made public, never uploaded to any cloud, and are accessed only by one authorised operator on the local machine.

6. 数据共享 / Data sharing

我们不与任何第三方（含云服务商、外包、关联方、其他卖家）共享、转让或出售通过本工具获取的任何亚马逊广告数据。唯一例外为安全事件响应：确认发生涉及亚马逊信息的安全事件时，我们将按亚马逊要求向其报告。

We do not share, transfer or sell any Amazon advertising data obtained through this tool with any third party (including cloud providers, contractors, affiliates or other sellers). The only exception is security incident response: a confirmed incident involving Amazon information is reported to Amazon as required.

7. 您的权利与联系 / Your rights and contact

本工具不收集买家个人身份信息，因此不涉及买家个人数据的访问、更正或删除请求。如您对本声明有任何疑问，可通过亚马逊卖家后台消息联系我们的运营团队。

As this tool does not collect buyer PII, there are no buyer personal-data access, correction or deletion requests involved. For any questions about this notice, contact our operations team via Amazon Seller Central messages.

8. 政策更新 / Policy updates

本页面内容如有变更，将在此处更新生效日期。本声明仅覆盖我们通过亚马逊广告接口处理自有店铺数据的方式。

If this page changes, the effective date above will be updated. This notice covers only how we process our own store data through the Amazon Ads API.
